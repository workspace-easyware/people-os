전사 · 요약 · 질문 · 코칭 · PPTX 초안 — HR과 코칭의 하루를 잇는 작업 공간입니다.

Cloudflare Workers 위에 만든 프로토타입입니다.

파이프라인

전사 → 요약 → 질문 → 코칭 → PPTX 초안
  • 전사 — 음성 파일을 올리면 Whisper가 텍스트로 바꿉니다. 긴 녹음은 구간별로 나눠 전사하고, 전사가 끝나면 요약·색인까지 자동 이어집니다.
  • 요약 — 전사본에서 핵심 요약과 액션을 뽑습니다. 액션은 할 일로 저장하고, PPTX 초안으로 내려받을 수 있습니다.
  • 질문 — HR 규정을 근거로 답합니다. 근거가 없으면 답을 지어내지 않고 답변 대기 목록에 기록합니다.
  • 코칭 — 코칭 전사본에서 핵심 질문과 패턴을 뽑아 다음 세션을 준비합니다.
  • PPTX 초안 — 요약으로 실제 .pptx 파일을 만듭니다. 개요를 먼저 고쳐서 만들 수도 있습니다.

데모 흐름

  • 홈 대시보드에서 현황을 보고, 업로드 탭에서 샘플 전사본을 불러옵니다.
  • 요약하고, 액션을 할 일로 저장하고, PPTX 초안을 내려받습니다.
  • 질문 탭에서 “연차 3일 쓸 수 있어?”라고 물어보면 규정 근거와 함께 답합니다.
  • 근거 없는 질문은 답변 대기 목록에 쌓이고, 담당자가 답을 달면 같은 질문에 암묵지 출처로 답합니다.
  • 코칭 탭에서 리플렉션을 만들어 봅니다.

쓰는 Cloudflare 기능

  • Workers — API·화면을 서빙하는 서버리스 백엔드
  • D1 — 문서·규정·세션·할 일·리플렉션 저장
  • R2 — 음성·문서 원본·PPTX 파일 저장
  • KV — 질문 캐시·속도 제한
  • Durable Objects — 대화 세션 기억
  • Workers AI — 전사(Whisper)·요약·답변·코칭·임베딩
  • Vectorize — 규정·문서 근거 검색
  • Queues — 전사 → 요약 → 색인 비동기 파이프라인
  • AI Gateway — AI 호출 캐시·속도 제한·로그
  • Cron — 매일 07:00 아침 다이제스트
  • Turnstile — 질문 폼 스팸·봇 방지
