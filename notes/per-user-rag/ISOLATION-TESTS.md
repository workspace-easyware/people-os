## 2. 전사본 질문 (골든셋 확장 후보, 5개)

## 4. 타 사용자 문서 누수 격리 테스트 (골든셋 확장 후보)

- 위 I-1~I-4를 그대로 평가 항목으로 옮긴다: 질문은 T-4/T-5(개인 문서 대상),
  실행 주체는 문서 소유자가 아닌 사용자(B·익명·admin)로 하고,
  기대 결과는 grounded=false + 출처에 소유자 문서 없음.
- 평가 실행기(runAsk, origin='eval')는 viewer가 없어 공용만 본다.
  따라서 격리 테스트는 평가 실행기가 아니라 **세션 사용자(B)로 /api/ask를 직접
  부르는 별도 절차**로 돌려야 한다 (verify.sh의 4번 섹션 참조).
  평가 실행기에 viewer를 넣으려면 runner.ts 변경이 필요 — 이번 작업 범위 밖.

## 5. 주의: JSON 경로 문서 색인 누락 (기존 문제, 이번 작업 범위 밖)

- POST /api/documents JSON 경로(kind='transcript' 기본)는 documents 행만 만들고
  indexDocument를 부르지 않아 chunk가 0개라 RAG에 전혀 안 보인다.
  프론트 텍스트 입력(954행)이 이 경로를 쓴다.
- 파일 업로드(multipart) 경로는 indexDocument를 타서 chunk가 생긴다.
- 이번 작업에서는 고치지 않았다 (동작 변경이라 부모 판단 필요).
  고치려면 JSON 경로에서 indexDocument(c.env, { id, title, markdown: body.content, kind, ownerId })를
  부르면 된다 (ownerId는 이미 구해져 있음).
